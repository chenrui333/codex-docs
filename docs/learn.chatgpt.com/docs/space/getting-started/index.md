# Get started with ChatGPT Space

Source: https://learn.chatgpt.com/docs/space/getting-started

> For the complete documentation index, see [llms.txt](https://learn.chatgpt.com/llms.txt). Markdown versions of documentation pages are available by appending `.md` to the page URL.

Create a page or slide deck from notes, files, or a conversation. You need an
account with Space enabled.

## Open Space

Open **Space** in ChatGPT. **All** brings together your saved work. Use
**Your items** to find your own content, **Shared with you** for content others
have shared, or search by name.

> Illustration: The All view in Space, with Suggested, Favorites, Your items, and Shared with you tabs, a search field, and a New menu.

## Draft your first page

<WorkflowSteps variant="headings">

1. Create a page

   Select **New page** in the sidebar. Give it a title and start typing, paste
   your notes, or add a file. You can also ask ChatGPT to create a page from an
   existing conversation.

2. Add context

   Include the notes, files, or links you want ChatGPT to use. For content in an
   app such as Google Drive, connect the app and point ChatGPT to the relevant
   files.

3. Ask ChatGPT to help

   Open ChatGPT alongside the page and describe what you want to make. Copy
   this prompt to organize rough notes:

**Prompt:**

```text
Organize the notes on this page into a clear draft. Use headings and bullet points where they help. Preserve the facts and source links, and list any open questions at the end.
```

4. Edit the result

   Change the text directly or ask ChatGPT for a revision. Check the result on
   the page before sharing it.

</WorkflowSteps>

## Create and refine slides

ChatGPT Slides lets you build a presentation with your team and ChatGPT in
Space. On mobile, you can create slides through conversation and view decks.
Use the web or desktop to edit slide elements directly.

<WorkflowSteps variant="headings">

1. Start with your material

   Ask ChatGPT to create a presentation in Space from a conversation, an outline,
   or source files. Describe the audience, goal, and length. You can also provide
   a reference deck or template to guide the layout and style.

**Prompt:**

```text
Create an 8-slide quarterly business review in Space using these notes and metrics. The audience is our leadership team. Cover results, risks, and decisions needed. Use the attached deck as a style reference, preserve the source numbers, and flag missing information.
```

2. Refine the deck

   Open the editable deck in Space. Edit text, images, shapes, tables, and charts
   directly, or select an element and choose **Request edits** to ask ChatGPT for
   a change. Use the prompt bar for changes across the deck, such as shortening
   the story for an executive audience. Ask ChatGPT to generate images or use
   visuals you upload.

3. Work with your team

   Share the deck and give collaborators edit access to work on the same slides
   at the same time. Use shared comments to discuss changes or mention ChatGPT
   or your dot to request a revision. See
   [Collaborate on slides](https://learn.chatgpt.com/docs/space/collaboration#collaborate-on-slides) for
   permissions and feedback.

4. Present or export

   Check the facts, charts, and layout before presenting. Present directly in
   ChatGPT with speaker notes, or export the deck. On the web, you can export to
   PowerPoint (`.pptx`), PDF, or Google Slides. In the desktop app, options to
   open the deck in PowerPoint or Keynote appear when those apps are installed.
   Review the exported deck's content and formatting before sharing it.

</WorkflowSteps>

If the Windows desktop app creates a PowerPoint file instead of a collaborative
deck, switch to cloud mode or use ChatGPT on the web to create and edit slides
in Space.

## Group related pages in a space

For a topic or team with related pages, create a space. From **All**, open
**New** and select **Space**. Name the topic or group, optionally expand
**Invite people**, then select **Create**. You can share the space later.

> Illustration: Create a space dialog with a name field, an Invite people option, and Cancel and Create actions.

People invited to a space receive access to its pages. To share only one page,
use that page's sharing controls instead. See
[inherited access](https://learn.chatgpt.com/docs/space/collaboration#understand-inherited-access).

## Review and share

<WorkflowSteps>

1. Open the page's sharing controls.
2. Choose a person or an available team and set their permission. Use view
   access for readers or edit access to work on the page together.
3. Share the link. Collaborators can open the page and, with edit access, make
   changes alongside you and ChatGPT.

</WorkflowSteps>
