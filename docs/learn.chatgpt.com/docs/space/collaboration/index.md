# Collaborate in Space

Source: https://learn.chatgpt.com/docs/space/collaboration

> For the complete documentation index, see [llms.txt](https://learn.chatgpt.com/llms.txt). Markdown versions of documentation pages are available by appending `.md` to the page URL.

Share a page on its own or, where available, share a Space to give people access
to a group of related pages.

## Choose an access level

The sharing controls show the permissions available for the page or Space.
Available roles also depend on the recipient type; a Team invitation may offer
view or edit access without comment access.

| Access  | Use it when someone needs to      |
| ------- | --------------------------------- |
| View    | Read the work.                    |
| Comment | Read the work and leave feedback. |
| Edit    | Change the content with you.      |

You need permission to manage sharing before you can change someone else's
access. Available recipients and sharing options depend on your account and
workspace.

For workspace sharing controls, see [Manage Space sharing](#for-workspace-admins).

## Share a page or Space

1. Open the page or Space you want to share.
2. Open its sharing controls and add the intended people or Teams from the
   available options.
3. Choose an access level and save.
4. Confirm that a collaborator can open the work with the expected permission.

Before sharing, check who can access the page and whether it contains information
from private sources.

## Understand inherited access

Access to a shared Space applies to its pages. Sharing a page also grants access
to its child pages. The sharing controls distinguish direct access from access
inherited from a parent page or Space.

Removing a direct invitation doesn't remove access that someone still inherits
from a parent page or Space. Review the parent or Space's sharing controls when
you need to change that access.

> Illustration: A page sharing dialog for Offsite plan shows workspace link access, the owner, and view access inherited from the Team offsite Space.

<a id="for-workspace-admins"></a>

**For workspace admins:** See [Manage ChatGPT Space](https://learn.chatgpt.com/docs/enterprise/chatgpt-space) for workspace sharing controls, setup, and security and governance guidance.

## Review together

Use comments to discuss a question or request a change. Give edit access to
collaborators who should update the content directly. When asking an agent to
revise shared work, identify the section it should change and preserve the
decisions your team has already made.

Check access to linked source material separately. A collaborator who can read
your page may still lack permission to open a source linked from it.

## Resolve an access problem

If someone can't open the work, check that they are using the intended account
and workspace, then review the page or Space's saved permissions. If you can't
edit or manage sharing, ask someone with the appropriate access to make the
change.

For guidance on developing the content together, see
[Pages](https://learn.chatgpt.com/docs/space/pages) and [Work with the agent](https://learn.chatgpt.com/docs/space/agents).
