# ChatGPT & Codex changelog | ChatGPT Learn

Source: https://learn.chatgpt.com/docs/changelog

```
$ npm install -g @openai/codex@0.156.0
```

  View details

## New Features

- Choose an optional fullscreen UI with `/tui` for your next launch, including transcript search, mouse selection, and right-click copying. ([#46732](https://github.com/openai/codex/pull/46732), [#46734](https://github.com/openai/codex/pull/46734), [#46883](https://github.com/openai/codex/pull/46883), [#46895](https://github.com/openai/codex/pull/46895))
- Voice conversations are enabled by default, with an F8 toggle, a `/voice settings` picker, and bundled audio runtimes for Linux and Windows. ([#44921](https://github.com/openai/codex/pull/44921), [#46071](https://github.com/openai/codex/pull/46071), [#44622](https://github.com/openai/codex/pull/44622), [#44714](https://github.com/openai/codex/pull/44714), [#44922](https://github.com/openai/codex/pull/44922))
- Explore account usage, token totals, and plugin and skill activity through the `/usage` analytics dashboard. ([#45764](https://github.com/openai/codex/pull/45764), [#45769](https://github.com/openai/codex/pull/45769))
- Filter tasks by status and create worktree sessions from the agent command center; worktree support is now enabled by default. ([#46839](https://github.com/openai/codex/pull/46839), [#45276](https://github.com/openai/codex/pull/45276), [#44870](https://github.com/openai/codex/pull/44870))
- Customize the terminal with six new themes and view supported Mermaid diagrams and display equations directly in responses. ([#46504](https://github.com/openai/codex/pull/46504), [#46054](https://github.com/openai/codex/pull/46054), [#45612](https://github.com/openai/codex/pull/45612))
- Update the local background server through `/daemon`, or bypass it with `--no-daemon`. ([#45854](https://github.com/openai/codex/pull/45854), [#46088](https://github.com/openai/codex/pull/46088))

## Bug Fixes

- Preserve streamed answers and plans when turns fail, are interrupted, or receive subagent completion events. ([#45549](https://github.com/openai/codex/pull/45549), [#46867](https://github.com/openai/codex/pull/46867))
- Fix clipboard forwarding in tmux and SSH sessions and preserve tab indentation when terminals send pasted text as individual keystrokes. ([#45457](https://github.com/openai/codex/pull/45457), [#45454](https://github.com/openai/codex/pull/45454))
- Restore Plan mode when resuming sessions and preserve thread identity and settings when editing earlier prompts. ([#45519](https://github.com/openai/codex/pull/45519), [#45845](https://github.com/openai/codex/pull/45845))
- Recover login through system proxies and refresh MCP credentials when OAuth discovery returns a 503 error. ([#46562](https://github.com/openai/codex/pull/46562), [#44636](https://github.com/openai/codex/pull/44636))
- Prevent speech from being dropped during playback pauses or bursts of incoming audio. ([#46880](https://github.com/openai/codex/pull/46880))
- Close sandbox isolation gaps involving inbound Windows connections, privileged Linux/macOS sockets, and writes through read-only macOS file handles. ([#44639](https://github.com/openai/codex/pull/44639), [#45984](https://github.com/openai/codex/pull/45984), [#46500](https://github.com/openai/codex/pull/46500))

## Documentation

- Clarify that deprecated `friendly` and `pragmatic` personality settings no longer select response styles. ([#45809](https://github.com/openai/codex/pull/45809))
- Explain how `?` matches a single character in network proxy allow and deny patterns. ([#46027](https://github.com/openai/codex/pull/46027))

## Chores

- Update bundled TLS dependencies, including OpenSSL 3.6.4 for Linux musl builds. ([#45149](https://github.com/openai/codex/pull/45149), [#45489](https://github.com/openai/codex/pull/45489))
